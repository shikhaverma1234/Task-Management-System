# **App Name**: Task Management System

## Core Features:

- Task Management: Create tasks with attributes: title, description, due date, priority, and status. Implement full CRUD (Create, Read, Update, Delete) operations for tasks.
- Dashboard: Tasks assigned to them. Tasks they created. Overdue tasks
- Search and Filter: Implement search by task title or description. Filtering based on status, priority, and due date.
- Technical Specifications: Frontend: Next.js. Backend: Node.js. Database: MongoDB

## Style Guidelines:

- Primary color: Clean white or light grey for the background.
- Secondary color: A calming blue (#3498db) for headers and accents.
- Accent: Green (#2ecc71) for indicating task completion or positive actions.
- Clean and organized layout with clear sections for tasks, dashboard, and user profile.
- Use simple, intuitive icons to represent task status, priority, and actions.
